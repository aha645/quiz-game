# 🎮 퀴즈 게임 (Quiz Game)

터미널에서 즐길 수 있는 간단한 퀴즈 게임입니다.

## 설치 / 실행 방법

```bash
# uv가 설치되어 있어야 함
uv sync           # 의존성 동기화 (의존성 없음)
uv run main.py    # 프로그램 실행
```

또는 직접 Python으로 실행:

```bash
python main.py
```

## 기능 목록

| 번호 | 기능     | 설명                                              |
|------|----------|---------------------------------------------------|
| 1    | 퀴즈풀기   | 등록된 모든 퀴즈를 순서대로 풀고 점수 계산         |
| 2    | 퀴즈추가   | 새로운 문제와 선택지를 직접 추가                   |
| 3    | 퀴즈목록   | 등록된 퀴즈 전체 목록 확인 (정답 포함)             |
| 4    | 점수확인   | 최고 기록 확인                                     |
| 5    | 종료     | 프로그램 종료                                      |

## 데이터 파일 설명

### `quiz_data.json`

퀴즈와 최고 점수를 JSON 형식으로 저장합니다.

```json
{
  "quizzes": [
    {
      "id": 1,
      "question": "문제 내용",
      "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
      "answer_idx": 0,
      "category": "카테고리"
    }
  ],
  "top_score": 50
}
```

| 필드         | 설명                                  |
|-------------|---------------------------------------|
| `id`        | 퀴즈 고유 식별번호                     |
| `question`  | 문제 내용                             |
| `choices`   | 선택지 목록 (4개)                      |
| `answer_idx`| 정답의 인덱스 (0~3)                    |
| `category`  | 문제 카테고리 (선택 사항)              |
| `top_score` | 최고 점수                              |

## 기술 스택

- **언어**: Python 3.12+
- **패키지 관리**: uv
- **데이터 저장**: JSON 파일 (`quiz_data.json`)
